# NYRA Festivals App 🎊✨

Official festival and community event management interface for the **$NYRA** ecosystem, built natively with SwiftUI.

## 🎯 Features
- **Event Calendar:** Track upcoming community launches and gatherings.
- **Native Integration:** Smooth iOS interface for event discovery.

## 🛡️ Transparency
This repository hosts the UI layer. All event coordination and logic are managed through secured community channels.
